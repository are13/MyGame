SLIME ENEMY - Pixel Art Sprite Pack
=====================================

A game-ready animated slime for RPG, platformer, roguelike or mobile games.

CONTENTS
--------
- Idle animation: 4 frames (gentle breathing bob)
- Hop animation: 6 frames (classic slime bounce)
- 4 color variants: Green, Blue, Purple, Pink
- Canvas: 16x24 px, transparent background
- Clean 3-color palette per sprite (body / outline / eyes)

FILES
-----
previews/       Animated GIF previews (8x scale, for viewing)
frames/         Individual transparent PNG frames (16x24)
spritesheets/   Horizontal strip sprite sheets (one PNG per animation+color)
cover.png       Showcase image (for store listing)

USAGE
-----
- frames/: import each PNG as a keyframe in your engine (Godot, Unity,
  GameMaker, Aseprite, etc.) and play in order at ~6-10 fps.
- spritesheets/: slice horizontally into 16x24 cells.
